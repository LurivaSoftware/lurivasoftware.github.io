Privacy Policy

AutoContenido is a personal desktop application for Windows that creates short videos and, when the user chooses to, uploads them to the user's own YouTube channels, Facebook Pages and TikTok accounts through the official APIs of those platforms. It is operated by its developer for his own accounts. There is no website account, no cloud service and no server run by the developer: the app runs entirely on the user's computer.

1Information the app accesses

  • YouTube (Google): permission to upload videos and set their title, description, tags and thumbnail, and to read the name of the connected channel. Scopes: youtube.upload, youtube.readonly.
  • Facebook (Meta): the list of Pages the user manages and a Page access token used to publish Reels to the Page the user selects. Permissions: pages_show_list, pages_read_engagement, pages_manage_posts.
  • TikTok: the account's display name and open ID, and permission to upload videos as drafts or posts. Scopes: user.info.basic, video.upload and, only if enabled, video.publish.

The app does not read messages, comments, followers, contacts, analytics, payment information or any other personal data. It never asks for or stores passwords; the user signs in on each platform's official page.

2How the information is used

Only to upload the videos the user creates to the account the user connected, and to show which account is connected. Data is not used for advertising, profiling, or any other purpose, and is not sold or rented.

3Storage and security

Access tokens are stored only on the user's computer, encrypted with Windows Data Protection (DPAPI), so they can be decrypted only by the same Windows user on the same computer. They are never sent to the developer or to any third party other than the platform they belong to.

4Sharing

Video files and their texts are sent only to the platform the user chose (YouTube, Facebook or TikTok) through its official API. To write video scripts, the app sends the video topic to the AI text service selected by the user (for example Groq or Google Gemini); no account data or tokens are sent to those services.

5Google user data

AutoContenido's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using the YouTube features you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

6Retention

Tokens are kept until the user disconnects the account in the app, deletes the app's credenciales folder, or revokes access on the platform.

7Data deletion and revoking access

  • In the app: Publish tab › Disconnect next to each account. This deletes the stored token from the computer.
  • Google / YouTube: myaccount.google.com/permissions › AutoContenido › Remove access.
  • Facebook: Settings & privacy › Settings › Business integrations (or Apps and websites) › AutoContenido › Remove.
  • TikTok: Profile › Settings and privacy › Security › Apps and services permissions › AutoContenido › Remove access.

Because the developer keeps no copy of any user data, there is nothing else to delete. Questions about deletion can be sent to the contact below.

8Children

The app is not directed to children under 13 and is not used to collect data from them.

9Changes

Changes to this policy will be published on this page with a new effective date.

Política de privacidad

AutoContenido es una aplicación personal de escritorio para Windows que crea videos cortos y, cuando el usuario lo decide, los sube a sus propios canales de YouTube, Páginas de Facebook y cuentas de TikTok mediante las APIs oficiales de esas plataformas. La opera su desarrollador para sus propias cuentas. No hay cuentas en un sitio web, ni servicio en la nube, ni servidores del desarrollador: la app funciona por completo en la computadora del usuario.

1Información a la que accede la app

  • YouTube (Google): permiso para subir videos y poner su título, descripción, etiquetas y miniatura, y para leer el nombre del canal conectado. Permisos: youtube.upload, youtube.readonly.
  • Facebook (Meta): la lista de Páginas que administra el usuario y un token de Página para publicar Reels en la Página que elija. Permisos: pages_show_list, pages_read_engagement, pages_manage_posts.
  • TikTok: el nombre visible y el identificador (open ID) de la cuenta, y permiso para subir videos como borrador o publicación. Permisos: user.info.basic, video.upload y, solo si se activa, video.publish.

La app no lee mensajes, comentarios, seguidores, contactos, estadísticas, datos de pago ni ningún otro dato personal. Nunca pide ni guarda contraseñas: el usuario inicia sesión en la página oficial de cada plataforma.

2Para qué se usa

Solo para subir los videos que crea el usuario a la cuenta que conectó y para mostrar qué cuenta está conectada. No se usa para publicidad ni perfiles, y no se vende ni se renta.

3Almacenamiento y seguridad

Los tokens se guardan solo en la computadora del usuario, cifrados con la Protección de Datos de Windows (DPAPI): únicamente el mismo usuario de Windows en la misma computadora puede descifrarlos. Nunca se envían al desarrollador ni a terceros, salvo a la plataforma a la que pertenecen.

4Con quién se comparte

Los videos y sus textos se envían solo a la plataforma que el usuario eligió (YouTube, Facebook o TikTok) mediante su API oficial. Para escribir los guiones, la app envía el tema del video al servicio de IA que el usuario seleccione (por ejemplo Groq o Google Gemini); no se envían datos de cuentas ni tokens a esos servicios.

5Datos de usuarios de Google

El uso que hace AutoContenido de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado. Al usar las funciones de YouTube aceptas los Términos de servicio de YouTube; consulta también la Política de privacidad de Google.

6Conservación

Los tokens se conservan hasta que el usuario desconecta la cuenta en la app, borra la carpeta credenciales o revoca el acceso en la plataforma.

7Eliminación de datos y revocar el acceso

  • En la app: pestaña Publicar › Desconectar junto a cada cuenta. Esto borra el token guardado en la computadora.
  • Google / YouTube: myaccount.google.com/permissions › AutoContenido › Quitar acceso.
  • Facebook: Configuración y privacidad › Configuración › Integraciones comerciales (o Apps y sitios web) › AutoContenido › Eliminar.
  • TikTok: Perfil › Ajustes y privacidad › Seguridad › Apps y servicios con permiso › AutoContenido › Quitar acceso.

Como el desarrollador no guarda ninguna copia de datos de usuarios, no hay nada más que eliminar. Dudas sobre la eliminación: al contacto de abajo.

8Menores

La app no está dirigida a menores de 13 años ni se usa para recopilar datos de ellos.

9Cambios

Los cambios a esta política se publicarán en esta página con una nueva fecha de vigencia.
